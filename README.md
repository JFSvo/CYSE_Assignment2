#### Steps to run the model ####

1. Run "git clone https://github.com/JFSvo/CYSE_Assignment2.git" in the directory where you want to download the repository. It may take a while since the model is 475MB.
2. Navigate to the CYSE_Assignment2 directory.
3. Create a python virtual environment using "python -m venv .venv/"
4. Activate the virtual environment.
5. Run "pip install -r requirements.txt".
6. Run all modules in the Jupyter notebook with that virtual environment selected.
